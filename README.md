# Home Credit LAP Qualification Voice Agent

## Project Overview
This project demonstrates an AI-powered voice agent built using Bolna AI to assist with Home Credit's Loan Against Property (LAP) qualification process.

## Objectives
- Explain the pre-approved Loan Against Property offer.
- Ask customers for permission to continue.
- Collect information required for preliminary eligibility checks.
- Identify disqualification conditions.
- Handle existing property loans by directing customers to a loan-transfer specialist.
- Arrange a callback from a senior loan expert for eligible customers.

## Key Features
- AI voice-based customer conversations.
- Property type and ownership checks.
- Original property document verification.
- Loan amount and repayment tenure checks.
- Employment and bank-income verification.
- Disqualification and specialist-referral handling.

## Technology
- Bolna AI voice-agent platform
- System prompting and conversational logic
- Voice call testing and transcript review

## Testing
The agent was tested with multiple customer scenarios, including eligibility checks, agricultural property disqualification, existing property loans, and loan amount limits.
